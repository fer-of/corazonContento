## 🎯 Descripción del Proyecto

[cite\_start]**Corazón Contento** es una plataforma móvil diseñada para reducir el desperdicio alimentario en negocios locales[cite: 153]. La aplicación permite a restaurantes, panaderías y tiendas de alimentos publicar productos que no se vendieron durante el día a un precio reducido, para que los consumidores puedan comprarlos, evitando que terminen en la basura.

Nuestros objetivos principales son:

  * [cite\_start]Reducir en un 20% el desperdicio alimentario en los negocios afiliados durante el primer año[cite: 153].
  * [cite\_start]Alcanzar 10,000 usuarios activos en los primeros 12 meses[cite: 155].
  * [cite\_start]Integrar al menos 50 negocios locales en el primer año[cite: 157].

## 🚀 Funcionalidades Clave

### Para Productores de Comida 👨‍🍳

  * [cite\_start]**Publicación de Alimentos**: Crear publicaciones rápidas de alimentos sobrantes con foto, descripción, fecha de caducidad y precio[cite: 6].
  * [cite\_start]**Panel de Estadísticas**: Acceder a un panel con estadísticas de ventas e inventario para entender qué productos tienen más demanda[cite: 6].
  * [cite\_start]**Gestión de Caducidad**: Marcar y destacar productos cercanos a su fecha de caducidad para darles prioridad[cite: 6].
  * [cite\_start]**Promociones**: Crear promociones y descuentos para atraer a más compradores[cite: 6].
  * [cite\_start]**Chat Integrado**: Comunicarse directamente con los clientes para resolver dudas a través de un chat seguro[cite: 6].

### Para Consumidores 🙋‍♀️

  * [cite\_start]**Notificaciones Personalizadas**: Recibir alertas sobre nuevos alimentos disponibles según la ubicación y preferencias[cite: 9].
  * [cite\_start]**Reserva y Pago Seguro**: Reservar y pagar los productos directamente desde la aplicación a través de un carrito de compra[cite: 9].
  * [cite\_start]**Reseñas y Valoraciones**: Consultar las calificaciones y comentarios de otros usuarios para asegurar la calidad[cite: 9].
  * [cite\_start]**Búsqueda y Filtros**: Encontrar alimentos específicos utilizando filtros avanzados por tipo, precio, ubicación y fecha[cite: 9].
  * [cite\_start]**Recolección Programada**: Elegir una ventana de tiempo definida para recoger los pedidos en el negocio[cite: 9].

## 🏁 Cómo Empezar (Getting Started)

Sigue estos pasos para configurar el entorno de desarrollo local.

### Prerrequisitos

  * Node.js (v18.x o superior)
  * npm o yarn
  * Git

### Instalación

1.  Clona el repositorio:
    ```sh
    git clone https://github.com/fer-of/corazon-contento.git
    ```
2.  Navega al directorio del proyecto:
    ```sh
    cd corazon-contento
    ```
3.  Instala las dependencias:
    ```sh
    npm install
    ```
4.  Inicia el servidor de desarrollo:
    ```sh
    npm run dev
    ```
